# Merkbestanden Pure Spirit

Bronbestanden van het logo en de huisstijl. Staat bewust buiten `public/`, dus
wordt niet op de website geserveerd.

| Map / bestand | Inhoud |
|---|---|
| `logo/pure-spirit-logo-origineel.png` | Origineel logo, 3061x2618, transparant, lichtblauw. |
| `logo/pure-spirit-logo-teal-246482.png` | Zelfde logo in de site-kleur `#246482` (--color-primary). |
| `print/` | Logo, kleurenoverzicht en briefpapier als PDF (van Sasja). |
| `fonts/Raleway/` | Huisstijlfont uit het logopakket (Regular, Medium, SemiBold, Bold, licentie OFL). |
| `og-pure-spirit.png` | Social-preview kaart 1200x630. De live kopie staat in `public/uploads/`. |
| `scripts/maak-og-kaart.cjs` | Maakt de kaart opnieuw (zie bovenin het script voor het commando). |

De website zelf gebruikt Cormorant Garamond (koppen) en Nunito (tekst), niet Raleway.
Het logo zelf (woordmerk in schreefletter) is een afbeelding, geen lettertype.
Header en footer gebruiken nog het oude kleine logo (117x95, lichtblauw) in
`public/uploads/`.
